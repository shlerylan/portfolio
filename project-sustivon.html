SustivonAI · Maritime UK ETS

Backend development for a maritime UK ETS compliance application, covering voyage and fuel data validation, emissions calculations, and allowance estimates.

Project overview

As an independent consultant, I contribute to SustivonAI’s maritime carbon compliance application, which turns voyage and fuel-consumption records into emissions and allowance estimates under the UK Emissions Trading Scheme (UK ETS). My work focuses on translating regulatory requirements into calculation logic that the team can implement, test, and review.

Responsibilities and deliverables

Requirements and technical design. Authored the Project Design Document and translated regulatory and functional requirements into testable calculation rules. Documented the input requirements and assumptions so the development team could refer to a common specification during implementation and testing.

Data validation. Implemented checks on voyage and fuel-consumption records before they entered the calculation workflow. These checks help the application identify input issues before producing emissions and allowance estimates.

Backend development. Developed Python and FastAPI backend components with PostgreSQL to calculate emissions and estimate allowance requirements. Verified calculation outputs against the documented rules to support repeatable compliance estimates.

Code availability

The source code is confidential under a non-disclosure agreement (NDA) and is unavailable for public access.
